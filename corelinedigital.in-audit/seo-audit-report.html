Audit & remediation

The site was well built. It just didn't say anything Google could match.

The site launched saying nothing Google could match to a search — no commercial keywords in any title, ~1,450 words total. Titles, schema and copy were rewritten; five new vertical landing pages shipped with real local photography and a fully-identified founder; site content reached ~7,047 words. Google API credentials configured along the way added something the earliest passes didn't have: real data — actual Lighthouse scores, live indexation status, real organic traffic, not estimates.

Two days ago this report found the deploy live but two pages invisible to Google. The sitemap has since been resubmitted, and indexation jumped from 2 of 4 pages to 9 of 11 — confirmed via Search Console's URL Inspection on every URL, not inferred. /services and /privacy have moved from "unknown to Google" to "discovered, not yet indexed" — a normal queue state, worth nudging with a manual Request Indexing rather than waiting out.

A second thing improved but didn't resolve: the mobile LCP regression flagged last pass moved from 3.3s to 3.1s — better, still past the 2.5s "good" line. A new diagnostic appeared this time: forced reflow, alongside the same ~1s of render-blocking requests as before.

Two real findings came out of this, one good and one to watch. First: the sitemap Search Console has on file was last submitted 28 August with the old 4 URLs. Two of your four previously-live pages were invisible to Google, which is the actual reason organic traffic reads zero — not a ranking problem. Resubmitting the now-11-URL sitemap and requesting indexing on /services and /work directly is the single highest- leverage action available right now.

Second: mobile Lighthouse performance moved from 95 to 88 between the two readings taken this session, and LCP crossed from 2.6s to 3.3s — past the "good" threshold. Desktop stayed perfect throughout. This tracks with how much the site grew this session (five new pages, more schema, a chat widget, more fonts) and is worth a look before it compounds further. What this audit could not measure

All five gaps below are missing credentials, not site defects. None of them are counted against the score.

  • Core Web Vitals (LCP, INP, CLS) - the PageSpeed Insights API returned HTTP 429 (daily quota exhausted, no key configured) and the Claude SEO runtime is not set up, so no CrUX field data was available. The performance score reflects direct transfer measurements only.
  • Indexation status - no Search Console access; the true indexed page count is unknown.
  • Backlink profile - no Moz, Bing or DataForSEO credentials; referring domains were not assessed.
  • Keyword rankings and search volume - no rank-tracking data source available.
  • Real-device mobile rendering - the Playwright MCP server failed to connect this session, so no screenshots were captured.
